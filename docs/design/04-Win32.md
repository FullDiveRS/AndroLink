# Design: AndroLink.Win32 (platform host)

The production `IPlatform` implementation over raw Win32 P/Invoke - no
WinForms, no WPF, nothing between AndroLink.UI and user32/gdi32/shell32.

## Window lifecycle

```
Win32Platform.CreateWindow(window)
  -> Win32WindowHost.EnsureWindowClass()   "AndroLinkUiWindow"
     CS_HREDRAW|CS_VREDRAW|CS_DBLCLKS, arrow cursor, null background brush
  -> CreateWindowExW(WS_OVERLAPPEDWINDOW, size adjusted via AdjustWindowRectEx)
  -> hosts[hwnd] = host (static dictionary; keeps WndProc delegate alive)
  -> ApplyDpi()  GetDpiForWindow -> Scale (DIP layout / pixel render)
  -> SetTimer(15 ms)                       animation pump
```

## Rendering

```
WM_PAINT:
  RenderIfDirty():
    GetClientRect -> EnsureSurface(w, h)
      CreateDIBSection 32bpp top-down  -> _dibBits
      SKSurface.Create(Bgra8888/Premul, _dibBits, stride)   <-- zero-copy
    Window.RenderFrame(canvas, scale):
      if layout dirty -> MeasureInternal + ArrangeInternal
      canvas.Scale(scale); clear; UiRenderer.RenderTree(root)
  BitBlt(DIB -> window DC)                  WM_ERASEBKGND returns 1 (no flicker)
```

Resize (WM_SIZE) recreates the surface at the new pixel size and re-lays-out.

## Input translation

| Win32 | Framework |
|---|---|
| WM_MOUSEMOVE (+ TrackMouseEvent) | DispatchPointerMove (DIP coords), hover enter/exit |
| WM_LBUTTONDOWN / DBLCLK / RBUTTON | SetCapture + DispatchPointerPress |
| WM_LBUTTONUP / RBUTTONUP | ReleaseCapture + DispatchPointerRelease |
| WM_MOUSEWHEEL | screen->client, delta/WHEEL_DELTA → DispatchPointerWheel |
| WM_KEYDOWN / WM_SYSKEYDOWN | virtual key map + Ctrl/Shift/Alt; letters pass as `Character` (Ctrl+C/V/X/A combos) |
| WM_CHAR | printable chars → TextInputEventArgs |
| WM_MOUSELEAVE | forced leave at (-1000,-1000) |
| WM_DROPFILES | DragQueryFileW → file list → `Window.DispatchFileDrop` |
| WM_DPICHANGED | re-scale + relayout |
| WM_GETMINMAXINFO | min track size 560x380 |
| WM_SYSCOMMAND | SC_MINIMIZE → hide to tray when `MinimizeToTray` |
| WM_APP_TRAY | tray icon callback (left click open, right click menu) |
| WM_APP_DISPATCH | `Post()` queue drain (backend threads → UI thread) |

## Platform services
- File dialog: `GetOpenFileNameW` with filter strings.
- Folder dialog: `SHBrowseForFolderW` (+ `SHGetPathFromIDListW`).
- Clipboard: CF_UNICODETEXT `GlobalAlloc`/`GlobalLock` round-trip.
- Reveal in Explorer: `ILCreateFromPathW` + `SHOpenFolderAndSelectItems`
  (files) / `explorer.exe /select` fallback.
- URLs: `ShellExecuteW("open", ...)`.
- Tray: `Shell_NotifyIconW` with tooltip + popup menu (Open / Quit).
- App icon: `LoadImageW(module, "#1", IMAGE_ICON)` from the embedded .ico.

## Notes
- `Win32WindowHost` is `internal`; the Manager accesses
  `MinimizeToTray` (public static) and everything else goes through
  `IPlatform`.
- All WndProc exceptions are caught + logged - a bug in a control degrades to
  a logged error instead of killing the message loop.
- Single message loop in `Run(Window)`; `PostQuitMessage` when the last
  window is destroyed.
